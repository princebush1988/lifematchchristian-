# Life Match Christian — Render-ready version

**Owner: Prince Bush, Founder & Owner.**
Christian dating app, worldwide. Real accounts, owner approval, Discover,
Like/Pass, matches, saved chat, voice/video calls (WebRTC, peer-to-peer).

> This is the standalone version made for Render hosting. It is NOT the
> Muse fullstack artifact (`life-match-christian-real-app`) — that one
> cannot be exported or put on Render. This code is the same app, rebuilt
> to run on its own server.

## What is inside

| File | What it does |
|---|---|
| `server.js` | Node + Express API + Postgres. Auth (email + PIN), Discover, Like/Pass, matches, saved chat, typing, KJV verse/prayer quick messages, WebRTC call signalling, Owner Console. |
| `public/index.html` | The whole app in the browser: Join / Sign in, Discover, Matches & Chat, voice/video calls, Owner Console, About & Safety. Blue design. |
| `schema.sql` | Postgres tables: users, likes, matches, messages, typing_states, call_signals. Also created automatically on boot. |
| `render.yaml` | Render Blueprint — creates the web service + database in one go. |
| `package.json` | `express` + `pg` only. Start command: `npm start`. |
| `.env.example` | Env vars to set on Render. Never commit a real `.env`. |

## How the app works

1. **Join:** a person signs up with email + PIN, name, age (18+), gender,
   who they are looking for, country, town, church, faith story, picture link.
2. **Owner approval:** every new profile starts `pending` and is **hidden**
   until Prince approves it in the Owner Console (passcode-protected).
   Prince can also reject, block, or remove anyone.
3. **Discover:** approved profiles only, with country / age / search filters.
4. **Like / Pass:** a match is made only when **both** like each other.
5. **Chat:** saved messages between matches only, unread badges,
   typing indicator, one-tap KJV verse and prayer messages.
6. **Calls:** voice/video calls between matches. WebRTC — the video goes
   phone-to-phone, not through the server. Both people must allow
   camera/microphone, and call quality depends on their internet.
7. **About & Safety:** Bishop Apostle Daniel J.B Scott's Word of Faith
   vision, safety rules, worldwide reach.

Without `DATABASE_URL` the server starts but the API returns
"Database is not connected yet" — that is normal until Render
gives it a database.

## Limits, honestly

- Video/voice calls are WebRTC peer-to-peer: both people need to
  allow camera/microphone, and quality depends on their internet.
  The call signalling (ring / offer / answer) is saved in Postgres;
  the actual camera/mic streams were not tested between two real
  phones in this build — test Step 3 with two phones before launch.
- Pictures are links for now (a member pastes an image URL). A
  proper photo upload needs file storage — a later change, once
  people are joining.
- No payment / subscription inside the app yet, and no App Store /
  Google Play listing yet — those are later steps, after the
  website version is running and people are joining.
